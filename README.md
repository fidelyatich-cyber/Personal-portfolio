# Personal Portfolio

A responsive personal portfolio website built with HTML and CSS and published with GitHub Pages.

**Live site:** https://your-username.github.io/personal-portfolio/

## About the project
The site introduces me, lists my education and interests, shows my technical skills, presents three projects and gives visitors a way to contact me. It was created as a web development assignment.

## Pages and sections
| Section | Contents |
|---------|----------|
| Home | Name, profile picture, short introduction |
| About me | Education (ordered list) and interests (unordered list) |
| Skills | Table of five technical skills |
| Projects | Four project cards (three completed data projects and one in progress) |
| Contact | Email address and contact form |

## Technologies
- HTML5 (semantic elements: header, nav, main, section, article, footer)
- CSS3 in an external file (variables, classes, IDs, Flexbox, Grid, media queries)
- Git and GitHub, GitHub Pages for hosting

## Folder structure
```
personal-portfolio/
├── index.html
├── style.css
├── README.md
├── images/
└── projects/   (project files)
```

## Run locally
1. Clone the repository: `git clone https://github.com/your-username/personal-portfolio.git`
2. Open `index.html` in a browser.
